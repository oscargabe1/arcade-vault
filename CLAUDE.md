## Project

Arcade Vault: online game platform where players compete for highest score. Early stage — still the create-next-app scaffold (`app/page.tsx` is boilerplate, layout metadata is default).

Per README: uses Spec Driven Design (`/spec` and `/spec-impl` workflow), following best practices from https://github.com/Klerith/fernando-skills (installed via `npx skills@latest add Klerith/fernando-skills`).

## Commands

- `npm run dev` — dev server (http://localhost:3000)
- `npm run build` / `npm start` — production build / serve
- `npm run lint` — ESLint (flat config, `eslint.config.mjs`)
- No test runner configured.

## Next.js version warning

Next 16.4.3 / React 19.3 — has breaking changes vs. training data. Read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`) before writing Next code. `AGENTS.md` is auto-regenerated by `next dev`.

## Architecture

- App Router only (`app/`), TypeScript strict, path alias `@/*` → repo root.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `experimental.agentFeedback`. `cacheComponents` changes caching/dynamic-rendering semantics — check docs before fetching data or using request APIs.
- Tailwind v4 via `@tailwindcss/turbopack` custom Turbopack rule for `*.css` (not PostCSS). Theme tokens in `app/globals.css` (`@theme inline`, light/dark via `prefers-color-scheme`).
- Root layout uses typed `LayoutProps<"/">` global helper and Geist fonts via `next/font/google`.
